## How to Run

1. Clone or download this repository.
2. Install Python and Jupyter Notebook (or use JupyterLab / Google Colab).
3. Install the libraries imported in the notebook. Common image-processing dependencies may include OpenCV and Matplotlib; check the notebook imports for the exact requirements.
4. Open `Swasti_BDA_ASS_2.ipynb` and run the cells in order.
5. Keep the image files in the same folder as the notebook so relative image paths continue to work.
